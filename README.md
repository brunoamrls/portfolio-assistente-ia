## 📖 Sobre o Projeto

Este repositório contém o código-fonte do meu portfólio pessoal, um site que não apenas apresenta minha trajetória, mas também a demonstra na prática. O projeto nasceu do meu desejo de aplicar os conhecimentos adquiridos nos cursos de **HTML e CSS** da Alura, onde aprendi a construir sites modernos e responsivos, seguindo boas práticas de desenvolvimento.

O grande diferencial é a integração de um **assistente de IA conversacional**. Inspirado na "Imersão Dev Agentes de IA com o Google", este assistente funciona como um guia interativo, capaz de responder a perguntas sobre minha carreira, projetos e competências, com base em um documento de conhecimento detalhado. Ele é a prova viva da minha busca por ser um profissional mais estratégico e completo, que utiliza a tecnologia para otimizar a comunicação e a análise de informações.

### 🎯 Meus Objetivos com este Projeto

- **Aplicar Conhecimento Prático:** Transformar o aprendizado teórico dos cursos de HTML, CSS e IA em um produto funcional e bem acabado.
- **Desenvolver Habilidades de Front-End:** Criar do zero uma interface limpa, responsiva e com uma experiência de usuário amigável.
- **Integrar Tecnologias:** Conectar um front-end (HTML, CSS, JS) a um back-end (Python, Flask), simulando um ambiente de desenvolvimento real.
- **Explorar IA Generativa:** Ir além do básico e construir um agente RAG (Retrieval-Augmented Generation) funcional, ajustando seu comportamento com engenharia de prompt.

---

## 🛠️ Tecnologias Utilizadas

### **Front-End (O Portfólio)**
- **HTML5:** Estrutura semântica e acessível.
- **CSS3:** Estilização moderna com Flexbox, Variáveis e Media Queries para responsividade.
- **JavaScript:** Manipulação do DOM e comunicação com o back-end via Fetch API.

### **Back-End (O Assistente de IA)**
- **Python & Flask:** Para a criação do servidor e da API.
- **Google Gemini:** Modelo de linguagem para a geração das respostas.
- **LangChain & LangGraph:** Orquestração do fluxo do agente de IA.
- **FAISS:** Banco de dados vetorial para a busca de informações.

### **Ferramentas e Versionamento**
- **Git & GitHub:** Controle de versão e hospedagem do código.
- **Vercel / GitHub Pages:** Hospedagem do front-end.
- **Render:** Hospedagem do back-end.

## 📝 Nota Importante sobre o Código-Fonte

Este repositório foi projetado para ser uma vitrine do meu trabalho, especialmente do código front-end. Por razões de segurança, para proteger a propriedade intelectual e a privacidade de informações pessoais do `prompt` que define a personalidade e as regras de negócio do agente, o código-fonte principal do back-end (`app.py`) e a base de conhecimento privada não estão incluídos aqui.

Para aqueles interessados na **estrutura completa** do agente de IA, a base do projeto pode ser encontrada no meu repositório [Projeto Agente de IA - Tutor para Desenvolvedores](https://github.com/brunoamrls/agente-ia-portfolio).
