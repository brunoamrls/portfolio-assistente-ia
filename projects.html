Portfólio com Assistente de IA Integrado

Portfólio desenvolvido em HTML e CSS com layout responsivo que apresenta trajetória profissional de forma interativa. Conta com assistente de IA conversacional integrado que responde perguntas sobre carreira, projetos e habilidades, funcionando como guia inteligente do site.

Tecnologias: HTML, CSS, JavaScript, Python, Flask, Google Gemini, LangChain, FAISS.

Landing Page - Ebook sobre UX e Operações

Este projeto, desenvolvido durante o bootcamp "Universia - Fundamentos de IA Generativa", é uma Landing page responsiva desenvolvida para apresentar o eBook "Entre Botões e Códigos". Utilizei o desenvolvimento Front-end para compreender na prática a arquitetura de interfaces, facilitando o diálogo com times de Produto sobre como a UX impacta a eficiência operacional e a redução de erros no Backoffice.

Tecnologias: HTML, CSS, IA Generativa (Conteúdo/Assets), GitHub Pages.

Pod&Dev - Player de Podcast com IA

Como parte de um projeto realizado para o bootcamp "Universia - Fundamentos de IA Generativa", desenvolvi uma interface web que apresenta o podcast Pod&Dev, contornando a limitação do GitHub de não suportar players de áudio. O player integrado permite a audição do episódio, cujo conteúdo foi inteiramente roteirizado e narrado, além de ter sua capa ilustrada com o auxílio de IA Generativa.

Tecnologias: HTML, CSS, Microsoft Clipchamp, IA Generativa (Gemini 2.5 Flash, ElevenLabs).
